# User flows

## Verified in code

- Home → Report → category → description → location/QR → submit.
- Home → Events → event list → event flow → name/email → registration.
- Home → Data → Supabase impact metrics → chart.
- Profile → 116-screen inventory → flow detail → action state.
- Profile → donation flow → validation → Supabase insert.
- Profile → Auth → email/password validation → Supabase sign-in/sign-up → result state.
